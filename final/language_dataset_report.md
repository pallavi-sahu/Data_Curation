## Cross-Language Metadata Patterns

| Field | Notes |
|---|---|
| Core fields | All records have `source`, `paragraph`, `language_code`, `detection_method`, `domain` |
| detection_method | `dataset` (bulk HF/Kaggle imports), `fasttext` (web/Wikipedia), `script` (Maithili/Santali web scraping) |
| confidence | Present for fasttext/script rows; typical range 0.85–1.0 |
| Chunking fields | `_chunk_index`, `_chunk_total`, `_word_count` (typically 300–450 words), `_input_line_number`, `_split_index`, `_split_from` |
| Paragraph length | ~1,300–9,600 characters; Tamil and Malayalam tend to be longest |
| Source types | HuggingFace datasets, Kaggle, Wikipedia, news/story sites, IndiaAI Aikosh, Project Madurai, local PDFs (Malayalam) |
